# Oct 1 以降の拡張機能ロードマップ

**対象期間**: Oct 1 - Dec 31, 2026  
**フェーズ**: Phase 2（本格運用後の機能拡張）  
**優先度**: High / Medium / Low

---

## Phase 2a: Oct 1-31 即効機能（優先度: High）

### 1. ライブ認定試験機能（Oct 10-20）

**目的**: Tier 2/3 認定試験をリアルタイムで実施

**機能**:
- **試験スケジュール管理**
  - 企業ごとに試験日時設定
  - Tier 2: 初級技術検定（90 分）
  - Tier 3: 上級システム設計（120 分）
  - 複数回受験サポート（最高スコア記録）

- **リアルタイム試験環境**
  - 問題のランダム出題（出題順序シャッフル）
  - 選択肢のランダマイズ（不正防止）
  - 制限時間・プログレスバー表示
  - ネットワーク断時の自動復帰

- **採点・結果配信**
  - 即座に合否判定
  - 詳細な項目別スコア表示
  - 回答解説表示（正答と誤答の根拠）
  - メール・push で結果配信

**実装先**:
- `lib/features/certification/exam_screen.dart`（試験画面）
- `lib/features/certification/exam_result_screen.dart`（結果画面）
- `functions/src/exam-*.ts`（採点ロジック）
- `lib/data/models/exam_model.dart`（試験データモデル）

**依存関係**: recordTrainingProgress のロジック再利用

**テスト項目**:
- [ ] 時間制限の正確性（±1 秒以内）
- [ ] 出題のランダム性（同じ問題が連続しない）
- [ ] 回答保存（ネットワーク切断時の復帰）

### 2. 企業別ダッシュボード（Oct 5-15）

**目的**: HR/マネージャー向けの進捗・実績ダッシュボード

**機能**:
- **リアルタイム統計**
  - 企業内の全従業員の進捗率（円グラフ）
  - モジュール別完了率（棒グラフ）
  - 日次完了数トレンド（折れ線グラフ）

- **従業員詳細**
  - 全従業員リスト（進捗率順）
  - 個別進捗確認（誰が何を完了したか）
  - 未完了者リスト（アラート対象）
  - 修了証発行確認

- **エクスポート機能**
  - CSV エクスポート（進捗一覧）
  - PDF レポート生成（経営層向け）
  - 定期メール配信（日次/週次/月次）

**実装先**:
- `lib/features/company_dashboard/company_dashboard_screen.dart`
- `lib/features/company_dashboard/employee_list_screen.dart`
- `functions/src/generate-report.ts`（PDF 生成）

**権限**: 企業管理者のみアクセス可能

**テスト項目**:
- [ ] リアルタイム統計の正確性（BigQuery との整合性）
- [ ] PDF 生成速度（< 5 秒）
- [ ] 大量データ処理（1000+ 従業員）

## Phase 2b: Nov 1-30 高度な機能（優先度: Medium）

### 4. 学習パス・パーソナライゼーション（Nov 5-25）

**目的**: 個人のニーズに合わせた学習

**機能**:
- **学習レベル診断**

  - 得意分野のスキップ機能

- **学習ペース管理**
  - 推奨学習スケジュール自動生成
  - 遅延時のアラート
  - 加速学習オプション（高成績者向け）

**実装先**:
- `lib/features/learning_path/` ディレクトリ新規作成
- Machine Learning: TensorFlow Lite で簡易推奨ロジック

**目的**: エビデンスベースの学習改善

**機能**:
- **学習パターン分析**

- **推奨アルゴリズム**
  - 高リスク学習者の自動検出

  - 効果的なコンテンツ組み合わせの提案

**実装先**:
- BigQuery ML で回帰分析
- Google Data Studio ダッシュボード作成

### 7. AI チューター（Dec 15-31）

**目的**: 24/7 学習サポート

**機能**:
- **Chatbot: 学習質問対応**
  - 自然言語で質問入力
  - Tier 1-3 コンテンツから回答検索・生成
  - 誤った回答には追加説明提供

- **自動採点・解説**
  - 記述式問題の自動判定（初期版）
  - 誤答時の詳細解説自動生成
  - 類似問題の提案

- **学習コーチ**
  - 学習進捗に基づいた励まし・アドバイス
  - 最適な学習時間帯の提案
  - 完了予測と目標達成支援

**実装先**:
- Cloud Natural Language API / Vertex AI
- Firebase Cloud Functions with LLM integration
- `lib/features/ai_tutor/` ディレクトリ新規作成

**注意**: API コスト管理・プライバシー保護が重要

## リスク管理

### 技術リスク
- **AI チューターの精度**: 初期版はテンプレートベース→段階的に LLM 化
- **スケーラビリティ**: 同時接続数増加への対応（Firestore シャーディング検討）
- **データプライバシー**: EU GDPR 対応が必要になる可能性

### ビジネスリスク
- **ユーザー獲得**: B2B 営業の成功に依存
- **競合**: 他の LMS プラットフォームとの競争激化
- **機能スコープ蔓延**: 優先度の厳格管理が必須

### 対策
- 2 週間スプリント開発で柔軟対応
- ユーザー検証を早期に実施
- 技術的負債の定期的なリファクタリング
